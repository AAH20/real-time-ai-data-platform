# Search and international-role positioning

Exact Google, LinkedIn and job-board search volumes are proprietary and change by geography and date. This repository does not invent numerical volume. It prioritizes broad category terms that recur across current platform documentation and senior data/AI architecture roles, then maps each term to evidence.

| Search and hiring term | Repository evidence | Claim status |
|---|---|---|
| Data Engineering / Data Platform | Event contracts, streaming architecture and lakehouse layers | Architecture plus executable decision slice |
| Microsoft Fabric | Eventstreams, Eventhouse, OneLake and Power BI target architecture | Adapter architecture; no live Fabric deployment |
| Power BI / Business Intelligence | Star schema, DAX measures and dashboard specification | Semantic artifacts implemented |
| Data Science | Transparent model, validation metrics and deterministic fixture | Implemented synthetic evaluation |
| Predictive Analytics | Delay probability, precision, recall, Brier score and confusion matrix | Implemented synthetic evaluation |
| Prescriptive Analytics | Expected-value action optimizer and intervention ledger | Implemented synthetic evaluation |
| Apache Kafka / Event Streaming | Versioned event schema and Redpanda development stack | Local contract and runtime scaffold |
| Change Data Capture / CDC | PostgreSQL-to-event-stream architecture | Architecture; Debezium runtime roadmap |
| Lakehouse / Delta Lake / Apache Iceberg | Medallion data-product and history layer | Architecture and semantic design |
| Azure Databricks | Lakehouse, model and AI Search integration path | Adapter architecture |
| Real-Time Analytics | 30-second freshness SLO and operational decision loop | Evaluated configuration |
| AI Agents / RAG / MCP | Permission-aware context serving path | Architecture; MCP server roadmap |
| Multi-Cloud | AWS Kinesis, GCP Pub/Sub and Azure event-source paths | Provider-neutral architecture |
| DataOps / MLOps | CI evaluation, deterministic receipt and promotion gates | Implemented baseline |
| Unit Economics | Cost per event, order, intervention and platform-dollar return | Implemented modeled inputs |
